# 内置知识目标示例

每个 goal 用一句自然语言表达知识目标。以下为已确认的目标设计；Content → Note 的代码调整待实现。Vault 在自身 `config.json` 中保存启用的 goals；Knowledge Task 的初始 prompt 冻结本轮 goals，恢复执行复用这一快照。

1. **Note**：从原始资料中提取值得复用的事实、经验和方法，整理成主题明确、可独立理解的笔记，并保留人物、背景和来源。
2. **Idea**：捕捉原始资料中尚未成型的想法、灵感、假设、观点或方向，用简短内容保留其原意、来源和未确定之处。
3. **Question**：从原始资料中识别尚未解决的问题，简要记录问题本身、相关背景和已有线索，并保留来源。
