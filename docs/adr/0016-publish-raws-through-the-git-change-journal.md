# Publish raws through the Git change journal

Ingestion Tasks publish through the existing Task Git lifecycle rather than a second commit/merge framework: `GitChangeJournal` and `GitChangeApplications` retain the Task-branch raw commit, then a generalized `TaskGitSynchronization` performs the three-way canonical publication and alignment. Raw preparations are owned directly by a typed Ingestion Task and require no Agent Run; Agent Tasks may synchronize only `wiki/**`, while Ingestion Tasks may synchronize only their dated raw namespace and cannot start Agent conflict resolution. The synchronization `published_head` is the canonical commit used to update `raws`; one final SQLite transaction records the applied Git operation, present/deleted raw projection, successful Task receipt and lifecycle, and Routine processing boundary. If Git publication lands before that transaction, retained journal evidence recovers the exact canonical commit and completes the transaction without invoking the Integration again.
