# Execute Ingestion inside Integrations

An Integration resource exposes a host-invoked `ingest({ integrationDirectory, outputDirectory, window })` operation that receives an exact Routine window and a host-owned output directory, writes raw files there, and returns `void` without involving an Agent. The window includes `start`, `end`, and the Routine's IANA time zone. The host derives additions, modifications, deletions, and no-change from Git rather than trusting a second provider-reported change list, so Agent-mounted extraction Skills, workflow instructions, executable paths, credential environments, `_workflow.md`, and `_updated.md` are removed; provider API clients or CLIs remain private implementation details of the Integration.

The operation reuses the existing sanitized `IntegrationError` contract. An ordinary provider failure becomes a failed Ingestion attempt, Effect interruption is classified by the host as cancellation or interruption, and publication conflicts remain Git synchronization outcomes rather than Integration errors; the Task receipt stores only a safe message and detailed attempt logging is outside this refactor.

The host records `cancelRequested` before interrupting the Effect fiber that owns `ingest`; the Integration receives no parallel `AbortSignal` or cancellation callback contract. Provider network and child-process effects must remain interruptible. Once interrupted, the host must not create or publish an Ingestion commit, and it classifies the attempt as `cancelled` only when the durable request exists, otherwise as `interrupted`.
